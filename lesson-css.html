תחילה, חשוב להבין היטב את התמונה הכללית לגבי מהות קבצי ה-html וה-CSS וכן הקשר ביניהם.

ליחצו לצפייה בשקף על HTML ו-CSS

בתוך קובץ HTML יש שני סוגי תגים: תגים סמנטיים שמתייחסים לחלקי הקובץ השונים, ותגי תוכן שמדפיסים תכנים על המסך. למדנו בקצרה את התגים העיקריים משני הסוגים.

ליחצו לצפייה ברשימת תגי HTML שנלמדו (התג p נשכח😒).
לחצו לצפייה בתמונת התגים הסמנטיים מהשיעור הקודם

מה צריך לדעת כדי להתחיל לעצב עם CSS:

  • תחילה יש לספר היכן נמצא קובץ העיצוב: < "link rel="stylesheet" href="style.css > כחלק מתגית head
  • מבנה חוק: selector { property: value; }
  • 3 סוגי סלקטורים: תגית, class ו- id:
    • תגית - להשפעה רחבה על כל הופעה של התגית בקובץ
    • class - לקבוצת אלמנטים שונים שברצוננו להעניק להם מראה זהה
    • id - נועד לעצב אלמנט יחיד וחד-פעמי בעמוד
  • מהם ה-properties המקובלים?
    • צבע טקסט ורקע: color, background-color
    • פונטים: font-size, font-family
    • יישור טקסט: text-align
  • מודל הקופסה: כל אלמנט מורכב מהתוכן שלו (content), ריווח (padding), מסגרת (border) ומשוליים (margin).
